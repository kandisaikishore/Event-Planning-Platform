# Event Planning Platform

An AI Studio application starter for an event-planning experience.

## Project overview

This repository contains application source and a local npm development path. Review the app screens and source code to identify the features that are currently implemented.

## Getting started

```bash
git clone https://github.com/saikishore2410/Event-Planning-Platform.git
cd Event-Planning-Platform
npm install
```

Configure required environment variables locally, then run the development/build scripts declared in `package.json`.

## Validation checklist

- Test event forms, date and time validation, and empty states
- Clearly distinguish demo events from persisted/live records
- Verify any calendar, notification, or booking integrations before advertising them
- Keep API credentials out of version control
- Add build and workflow tests where practical
